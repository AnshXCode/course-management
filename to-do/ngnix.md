Typical responsibilities of an API Gateway
Routing requests to the correct service
Authentication and authorization
Rate limiting
Load balancing
SSL/TLS termination
Request/response transformation
Logging and monitoring
Caching

Do we have to pay ngnix to handle all this
No. Most companies use the free, open-source version of NGINX, and it already supports many features such as:

Reverse proxy
Load balancing
SSL/TLS termination (HTTPS)
Static file serving
Basic rate limiting
Caching
Basic API gateway functionality
